  - The idempotency key is kept on 403 (`DROP_KEY_STATUSES` = 400/404/422), and the key path is concrete per customer.
  - Protected queries are `enabled` only while verified (all except the one noted in #7).
  - Generated types only.
  - No `localStorage`/`sessionStorage` use in slice 03.
  - The traceability rows are updated.
