## Checked and found conformant (no finding)
- **SpaForwardController (E2.1)** handles GET only. It forwards when the decoded first segment, with matrix parameters stripped, is not `api|actuator|error|v3|swagger-ui` and the last segment has no dot. `GET /` is forwarded, which is harmless. `/error/x` isn't forwarded, consistent with "not under `/error`". The forwarded `index.html` gets `no-cache` and `/assets/**` gets `max-age=31536000, immutable` (both asserted in `SpaForwardIT`). Vite's `dist/assets` layout matches.
- **ProfileGuard (E2.5)** is an `EnvironmentPostProcessor` that runs after config-data profile resolution and fails `prod,e2e` before any bean starts. `application-e2e.yml` changes only L1, which `ProfileGuardIT` asserts.
- **Security:**
  - No `dangerouslySetInnerHTML`, `location.*` navigation, token storage or `console.log` in `src/`.
  - The persist store writes only `sidebarCollapsed` (`uiStore.ts:26`).
  - `X-XSRF-TOKEN` is read from the cookie at send time.
  - Login `variables` are dropped (`gcTime: 0` plus `reset()`).
  - `ApiError` is built from the response only.
  - `e2e/.auth/` is git-ignored.
- **State and types:** server state is only in TanStack Query. API types come only from `types/api/01-foundation.ts` (generated, with the `gen:api:check` drift gate).
- **Tests:** every §10 test file exists. There are no `.only` or `.todo` tests. The one `test.skip` (`responsive-a11y.spec.ts:108`) is the documented budget gate.
- **E2E login budget:** 7 (setup) + 4 (session) + 1 (mobile keyboard login) = 12, with `retries: 0`.
- **Console guard** (`test/setup.ts`): it fails a test on any unexpected `console.error`/`warn`. Opting out requires an explicit per-test spy (used twice in `states.test.tsx`, both for the documented `RouteErrorPage` log).
- **F22 focus:** a drawer close caused by navigation focuses the new `<h1>`. An Esc or close-button close returns focus to the menu button.
- **Dependencies:** all are imported somewhere (jsdom via the Vitest `environment`).
