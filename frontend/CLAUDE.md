# Frontend rules (React + TypeScript + Vite)

## Stack (BRD §10, do not substitute)
Tailwind CSS v4 · shadcn-style primitives in `src/components/ui` (Radix + cva) · lucide-react icons ·
React Router v8 (data router, package `react-router`) · TanStack Query v5 (server state) · Zustand (session/UI state only) ·
TanStack Table v8 · React Hook Form + Zod · Recharts · Vitest + Testing Library · Playwright.

## Structure (BRD §10.1)
```
src/app/            providers, router, AppShell, route guards
src/components/     ui/ (primitives), layout/ (Sidebar, Header), data-table/, feedback/ (states)
src/features/<area>/<feature>/   api.ts (query hooks), schema.ts (zod), components/, pages/
src/services/       http.ts (fetch wrapper: CSRF, correlation id, ProblemDetail), api-types.ts (generated)
src/stores/         session.ts (Zustand)
src/permissions/    permission constants + <Can permission=…> + useHasPermission
```

## Conventions
- Data fetching only via `src/services/http.ts`; query keys are arrays starting with the feature name.
- Types for API payloads come from `src/services/api-types.ts` (generated by `npm run gen:api`). Do not hand-write them.
- Every page renders `<LoadingState/>`, `<EmptyState/>`, `<ErrorState/>` from `components/feedback` as appropriate (XC-03).
- Forms: RHF + `zodResolver`; show field errors under inputs with `aria-describedby`; disable submit while pending
  and send an `Idempotency-Key` (uuid created once per form submit attempt) for create/payment actions (CUS-06.6).
- Navigation items and actions are gated by permission via `<Can>`; routes via `<RequirePermission>` (XC-01/02).
  This is UX only; the backend is the authority.
- Never use `dangerouslySetInnerHTML`. Never store tokens or PII in localStorage.
- Visual language: navy sidebar (`--sidebar`), blue primary, white cards, rounded-xl, subtle borders (see BRD mockups).
- Accessibility: semantic elements, labels for every input, visible focus ring, keyboard-operable dialogs.
