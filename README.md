# Telecom Customer Support — an AI‑native engineering case study

A production‑grade **monolith** (React + Spring Boot + MySQL) for a postpaid telecom operator's customer support. No line of code in this repository was written by hand; everything was generated by Claude Code, steered by the project's own *context, skills, hooks, subagents, MCP servers, commands and CI review*.

- Business requirements: [`docs/brd/brd.md`](docs/brd/brd.md) (converted from the original `.docx`)
- How the AI capabilities were introduced, one problem at a time: [`docs/ai-journey/`](docs/ai-journey/)

## Branch strategy

Each branch introduces one Claude capability, documents the problem we saw *without* it, and uses it to ship one BRD delivery phase.

| # | Branch | Capability | BRD phase |
|---|---|---|---|
| 1 | `ai/01-context-memory` | `CLAUDE.md`, ADRs, BRD→stories skill | Skeleton |
| 2 | `ai/02-project-skills` | Project skills | Phase 1 Foundation |
| 3 | `ai/03-hooks-guardrails` | Hooks + ArchUnit | Hardening |
| 4 | `ai/04-subagents` | Subagents | Phase 2 Customer portal |
| 5 | `ai/05-mcp` | MCP (MySQL, Playwright, Context7) | Phase 3 Inbound |
| 6 | `ai/06-workflow-commands` | Slash‑command workflows | Phase 4 Outbound |
| 7 | `ai/07-ci-ai-review` | CI + Claude PR review | Phase 5 Business |
| 8 | `ai/08-production-readiness` | Security/DevOps review | Phase 6 |
